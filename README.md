# Symulator ruchu drogowego

Projekt symuluje ruch pojazdów w sieci skrzyżowań, zarządza flotą aut i mierzy przepustowość (w tym raporty dla skrzyżowań oraz korytarzy transportowych).

## Plik wykonywalny (EXE)

Gotowy plik aplikacji znajduje się tutaj:

- `dist/symulator.exe`

## Uruchomienie z kodu (opcjonalnie)

- Tryb interaktywny: `python main.py`
- Tryb automatyczny (raport): `python main.py --auto`
